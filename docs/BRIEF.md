## 0. 任务

设计**两张独立的桌面端界面**,它们共用同一套 UI Design System:

- **01 HOME / 工作台** —— 进入系统后的主界面
- **02 SETTINGS / 设置** —— 系统配置

**必须严格延续启动动画的视觉语言。** 这不是"另做一套风格",而是启动动画那套语言的延续与展开:
两张界面放在一起要能被认成同一个系统。

---

## 1. 视觉语言

### 1.1 定位

极简未来主义 · 工业控制台 · 瑞士排版 · 精密 HUD · 编辑式排版 · 高端 AI 系统。

### 1.2 必须遵守

| 项 | 要求 |
|---|---|
| 底色 | 暖白(不是纯白,不是灰) |
| 主文字 | 黑 |
| 次要文字 | 浅灰 |
| 强调色 | **Deep Orange,极少量** —— 只用于状态与活动态 |
| 整体 | 低饱和、低对比、克制 |
| 留白 | 充足 |
| 边框 | 1px |
| 分割 | 细线 |
| 网格 | 精确 |
| 画布 | 16:9 桌面端 |
| 侧边栏 | 固定宽度 240–260px |
| 结构元素 | 极细建筑辅助线 + 极细 L 型定位角标 |
| 间距系统 | 8px / 4px |
| 文字 | 中文为主体 + 英文 ALL CAPS 宽字距 |
| 系统信息 | Monospace |
| 材质 | 极轻微的纸张/数字噪点 |

### 1.3 明确禁止

- 渐变
- 玻璃拟态(Glassmorphism)
- 霓虹 / Cyberpunk
- 游戏 HUD
- 3D
- 强阴影

### 1.4 色彩

从参考图取样的基准值:

| 用途 | 值 |
|---|---|
| 页面底 | `#efedea` |
| 卡片面 | `#f4f3f1` |
| 主文字 | `#151514` |
| 强调橙 | `#ff7500` |

### 1.5 文字层级

层级靠**字号与字距**拉开,不靠颜色。

**字体名单(原文明确给出)**:

| 用途 | 候选 |
|---|---|
| 中文 | Noto Sans SC · PingFang · Helvetica Neue |
| 英文系统信息 | IBM Plex Mono · DIN · Inter · Monospace |

- **标题**:粗体、**低字重变化**、较大字号
- **系统信息**:小字号 + **高字距**
- **英文辅助文字**:ALL CAPS + WIDE LETTER SPACING
- 中文与英文之间保持**明显层级差**

## 2. 屏幕 01 · HOME / 工作台

### 2.1 左侧边栏

- 顶部:**DeepSeek logo** + `HARNESS` 徽标
- **新会话 / NEW SESSION**
- **插件 / PLUGINS**
- **工作区 / WORKSPACE**,并带 搜索 / 筛选 / 新建 三个功能入口
- 工作区列表:**我的工作区**、**默认工作区**
- 底部:**账号信息**

要求:界面简洁,支持"收缩/展开"的语义(内容分组清晰,不堆功能入口)。

### 2.2 顶部系统信息条

`REV 0.1.0` · `WEB PROFILE` · 时间(如 `18:32:04`)

- 时间用**橙色**
- 其余用灰色
- 附带极细的刻度装饰

### 2.3 中央 Hero(核心视觉)

**多个不同半径、互相错位的圆弧**,配合少量细节:

- **绝不画完整圆**
- 黑色 + 浅灰 + 极细白色弧线混用
- 少量**橙色状态点**
- 标题在中央:`探索未知之境`
- 副标题英文:`EXPLORE THE UNKNOWN`
- 标题周围保持**大量留白**

### 2.4 输入区

- 尺寸:**650–750 × 100–120px**
- **1px 边框**,轻微阴影
- 占位文本:`描述你想要构建的内容，例如…`
- 底部工具行:`＋` / `工作区内搜索` / 模型
- 右侧:`DeepSeek V4.1-Flash`
- 发送按钮:**橙色圆形**

### 2.5 快捷操作

输入区下方三个胶囊按钮:

**文件上传** · **知识库** · **生成图像**

### 2.6 底部 HUD

- **橙色信号柱**(信号强度样式)
- `[ 01 / 06 ] HOME`
- `等待用户输入... / AWAITING USER INPUT`
- **细进度条**:黑色线 + **一个橙色节点**
- `POWERED BY DEEPSEEK`

## 3. 屏幕 02 · SETTINGS / 设置

### 3.1 设置导航

与 HOME 相同的侧边栏之外,再加一列设置导航,**7 项**:

| 项 | 英文 |
|---|---|
| 账号与余额 | ACCOUNT |
| 通用设置 | GENERAL |
| 模型 | MODEL |
| 内置插件 | PLUGINS |
| Agent 预设 | PRESETS |
| 启动动画 | BOOT SEQUENCE |
| 侧边卡片 | SIDE CARDS |

每项:**线性图标 + 中文 + 小号英文**;活动态为**橙色左边线**。

### 3.2 头部

`设置 / SETTINGS` + 「打开配置文件」按钮 + 关闭。

### 3.3 内容布局原则

**用细线、留白与文字层级建立纵向模块化布局,不要大面积卡片。**

### 3.4 通用设置

- **主题**:`LIGHT` / `DARK` / `SYSTEM` 分段控件
- **语言**:`中文` / `ENGLISH`
- **动画**、**启动动画**、**HUD 效果** 开关
- **默认工作区**
- **自动保存**、**历史记录**

### 3.5 模型

展示 模型名称 / 状态 / 上下文 / 速度 / 推理能力 ——
用**极细的横向参数条**呈现,**不要做成数据 Dashboard**。

### 3.6 内置插件

纵向列表:名称 + 简述 + 状态 + 开关;
细分割线;**激活时用橙色状态点**。

### 3.7 Agent 预设

`01–05` 编号:Research / Design / Coding / Writing / Custom;
右侧 `ACTIVE` / `INACTIVE`;**选中时橙色短竖线**。

### 3.8 启动动画

设置中加入启动动画管理,展示**六个启动阶段**(原文逐条列出):

```
01  ACCESS PERMISSION
02  IDENTITY VERIFICATION
03  SYSTEM INITIALIZATION
04  SYSTEM CHECK
05  VERIFICATION
06  HARNESSS OS
```

> 注:原文第 06 项写作 **`HARNESSS OS`**(三个 S)—— 这是"品牌写法"冲突的来源之一,
> 见第 5.1 节。本仓库实现采用两 S。

采用**横向或纵向 Timeline**:

- 细灰线
- 黑色节点
- **橙色当前节点**

**严格对应参考图前三张启动画面的设计语言。**

### 3.9 侧边卡片

卡片级开关。

### 3.10 系统微细节(DETAILS)

原文单列了一节"系统微细节",作为视觉辅助信息:

```
REV 0.1.0      SYSTEM READY    CORE ONLINE    SESSION ACTIVE
WORKSPACE      STATUS          ACTIVE         READY
```

要求:

- 字号**非常小**、颜色**浅灰**
- **不要让这些信息抢主体**
- 另加:细刻度 · 短横线 · 坐标 · 编号 · 状态点 · 微型进度条
- **但必须克制**

## 5. 待确认项

### 5.1 品牌写法

- 需求文本里写作 **`HARNESSS`**(三个 S)
- 参考图与启动动画中实际是 **`HARNESS`**(两个 S)

> **已决策(2026-10-05,用户拍板):统一采用 `HARNESSS`(三 S),以需求原文为准。**
> 已改动的渲染位置:预览页侧栏徽标(`brand__badge`,home/settings)、启动序列第 06 项、
> 封面页字标、帧层品牌标记(`hos-brand`)与设置行标题(两个仓库);
> 主题包的设置行标题与主题名同步修改,`lib/client.js` 已重新生成,两仓库门禁全绿。
> 代码标识符(插件 id、仓库名、类名)不受影响。

### 5.2 参考图标注的 6 处细节

原参考图另附 6 处界面细节说明:

1. **新会话按钮** —— 一键开启新对话,支持快捷键、多窗口
2. **输入框功能增强** —— 文本 / 文件 / 知识库 / 生成图像,可选模型
3. **底部状态栏** —— 对话进度、工作区位置、输入状态、品牌标识
4. **右下角助手角色** —— 提供提示、功能引导与情绪陪伴
5. **设置面板结构** —— 卡片式布局,清晰展示账号信息、功能分类与操作按钮
6. **主题与视觉风格** —— 延续启动动画的极简科技风格,以白/灰为主,橙色为点缀

> 注:第 5 条"卡片式布局"与第 3 节"不要大面积卡片"存在字面冲突。
> 本实现的处理方式是:用**模块化分区**(标题 + 英文副标 + 细分割线 + 参数行)
> 代替卡片堆叠,在同一视觉目标下同时满足两条 —— 分区清晰但不靠卡片。
