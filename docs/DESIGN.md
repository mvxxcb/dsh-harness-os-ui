# HARNESS OS · Desktop UI

**进入系统后的桌面端界面设计 —— 两张独立界面,同一套 UI Design System。**

严格延续启动动画的视觉语言:暖纸白底 · 黑色主文字 · 浅灰辅助 · 极少量 Deep Orange 作强调 ·
极细结构线与 L 型定位角标 · Monospace 系统信息 · 中英双语层级。

## 设计系统

### 色

暖白为底、黑为字、橙只做**状态与活动**。全屏橙色出现次数控制在个位数量级 —— 橙一多,
"克制"就没了。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` | `#f1efec` | 页面底 |
| `--paper-rail` | `#eeebe7` | 侧栏(比主区略沉) |
| `--surface` | `#f8f7f5` | 抬升面:输入框、选中行 |
| `--ink` | `#14130f` | 主文字 |
| `--ink-3` / `--ink-4` | `#8b8780` / `#b5b0a8` | 辅助 / 极弱(刻度、编号) |
| `--line-l1…l4` | 6% → 24% 黑 | 辅助线 → 结构边框,四级细分 |
| `--accent` | `#ff7500` | 唯一的暖色 |

**不用阴影分层,用线分层。** 抬升面只比底色亮一点点,靠 1px 细线建立边界 —— 这是
"工业控制台"与"网页卡片"的分水岭。

### 字

中文现代无衬线 + 英文等宽。**层级靠字号与字距拉开,不靠颜色**。

| 角色 | 字体 | 规格 |
|---|---|---|
| 中文主标 | Noto Sans SC / PingFang | 42px / 700 / 字距 .14em |
| 中文正文 | 同上 | 13px / 400 |
| 英文辅助 | IBM Plex Mono | 11px / ALL CAPS / 字距 .18em |
| 系统信息 | 同上 | 10px / ALL CAPS / 字距 .14em |
| 刻度编号 | 同上 | 9px |

英文一律 **ALL CAPS + 宽字距**,与中文形成明确层级差;系统信息一律 **Monospace + 表格数字**
(`font-variant-numeric: tabular-nums`),这样时间走动时不会抖动。

### 间距与圆角

8 / 4 系统(`--s1…--s9`)。圆角克制:`2 / 3 / 4 / 6px`,只有胶囊按钮与状态点用 `999px`。

### 组件语言

`1px 边框 · 小圆角 · 细分割线 · 线性图标 · 紧凑按钮 · 小号标签 · Monospace 元信息 · 橙色活动态`

活动态的实现统一为**左侧一根 2px 短橙线**(导航、Agent 预设)或**橙色文字 + 极淡橙底**
(segmented control)。不用填充色块。

### 结构

- 固定左侧栏 **248px**(brief 的 240–260 区间) + 主内容区
- 页面四周 `32px` 留白,内容栏最大宽度 `1180px`
- **屏幕四角 1px L 型定位角标**(`.corners`,内缩 16px)
- **垂直辅助线落在有意义的位置**:HOME 对齐输入框左右边缘(650–750px 宽度带),
  SETTINGS 对齐内容栏左边界。**不为了"有辅助线"而横切画面**
- 水平结构由 Hero 下沿的一条 1px 线承担 —— 它同时是"水平辅助线"与真实的分区边界

### 材质

极轻微纸张噪点(SVG `feTurbulence`,整体透明度 **3.5%**)。几乎不可察觉,
只是让大面积底色不"死"。没有渐变、没有玻璃、没有金属、没有 3D、没有强阴影。

## 两张界面

### 01 HOME / 工作台

```
┌ 侧栏 ────────────┬ 系统信息条:REV 0.1.0 · WEB PROFILE · 刻度 · 时间(橙) ─┐
│ deepseek HARNESS │                                                      │
│ + 新会话         │            AI Core(错位圆弧 + 橙色状态点)             │
│ ⬡ 插件           │                                                      │
│ 工作区  ⌕ ⌗ ＋   │              探索未知之境                              │
│  我的工作区   03 │              EXPLORE THE UNKNOWN                     │
│  默认工作区   01 ├──────────────────────────────────────────────────────┤
│                  │   输入区(720×112,1px 边框,极轻阴影)                  │
│                  │   文件上传 · 知识库 · 生成图像(胶囊)                   │
│ 账号             ├─ HUD:[01/06] HOME · 等待用户输入… · POWERED BY ───────┤
│                  │   进度条(黑线 + 橙色活动节点)                         │
└──────────────────┴──────────────────────────────────────────────────────┘
```

Hero 的 AI Core 是手绘 SVG:5 段**不同半径、不同颜色、互相错位的开放圆弧**(不画完整圆),
3 个橙色状态点,3 处定位十字,1 个中央准星。外两层极慢反向自转(96s / 140s),
`prefers-reduced-motion` 与设置里的「动画」开关都会让它静止。

### 02 SETTINGS / 设置

结构上**与 HOME 完全一致**:同一侧栏、同一条系统信息条、同一套 HUD 语言。
右侧多出一列设置导航(208px),内容区按模块纵向排布 —— **不用大面积 Card**,
靠"标题 + 英文副标 + 细分割线 + 参数行"建立层次。

7 个面板(点击导航切换,活动项橙色左边线):

| 面板 | 内容 |
|---|---|
| 账号与余额 | 登录态、充值/赠金余额、查询用量 / 充值 |
| **通用设置** | 界面设置(主题 LIGHT/DARK/SYSTEM · 语言 · 动画 · 启动动画 · HUD 效果)、工作区设置(默认工作区 · 自动保存 · 历史记录)、系统信息 |
| 模型 | 当前模型 + 5 条**极细横向参数条**(STATUS/CONTEXT/SPEED/REASONING/OUTPUT),不做数据 Dashboard |
| 内置插件 | 纵向列表:名称 + 简述 + 版本 + Toggle,激活处橙色状态点 |
| Agent 预设 | `01–05` 编号 + 名称 + ACTIVE/INACTIVE,选中橙色短竖线 |
| 启动动画 | 六阶段 Timeline(细灰线 / 黑节点 / 橙色当前节点)+ 播放设置 |
| 侧边卡片 | 卡片级开关 |

控件统一为**精密的小型 Segmented Control 与 Toggle**(30×15),尺寸克制。

## 两点说明

**1. 字体是回落链,不是内置字体。** Noto Sans SC / IBM Plex Mono 未随附(不引入网络请求),
页面使用系统栈回落。若要做像素级还原,应把这两套字体放进 `assets/fonts/` 并加 `@font-face`。

**2. 品牌写法。** 设计要求文本里写作 `HARNESSS`(三个 S),而参考图与启动动画中实际是
`HARNESS`(两个 S)。本实现**统一采用参考图的 `HARNESS`** —— 视觉参考优先于文本手误。
如需改成三 S,`brand__badge` 与启动序列第 6 项各改一处即可。
